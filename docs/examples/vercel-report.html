The shape of it · the author's reading

The dashboard code is thickest around AI Gateway and agents: a gated private inference area, a marketplace model playground, an agent builder with a free credit tier, an MCP chat with upgrade prompts, and Vercel Agent credits and bulk suggestion handling. A second cluster is money and movement inside the account: a support chat that handles refunds and invoice changes, project transfers that check for storage and paid features that will not move, integration configurations that transfer between teams, and an automatic refund event. The job board leans the same way (Agent Auth, Connect, Agentic Infrastructure, Software Factory, Scheduled Tasks), while the sitemap carries 130 compare and alternatives pages that no public page read links to yet.

Read as Vercel the deployment platform at vercel.com. Read 4,456,597 bytes of first-party code in 60 scripts, 2 pages, the certificate logs, 87 Greenhouse postings, the pricing page, 200 changelog entries, 28 docs pages and robots.txt. The gap that matters: the engine enumerated 110 scripts and read 60 under its cap, and the docs index was the 28-page llms.txt, so a feature described only on a deeper docs page can look unmentioned here. Full coverage at the end.
