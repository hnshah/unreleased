The shape of it · the author's reading

The code that is not yet public is almost all agent plumbing. Coding sessions are growing admin controls (workspace keys, effort, model, quota), pull requests are getting an agent slot of their own, and the Linear Agent is being given per-team skills, connectors and a standing role on projects. Integration work widens the surface on the code host side: GitLab and GitHub Enterprise. The marketing bundle adds nothing new; the sitemap holds a switch campaign built but not linked.
