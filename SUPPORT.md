# Support

- **Something looks wrong in a brief** (a finding that is not what it says, a missing announcement, a host
  that should have been withheld): open an issue with the product, the run id from the footer line and the
  line in question. Receipts make these fast to check.
- **A product you want excluded**: open an issue titled "Exclusion: <product>" from a company address, or
  email the maintainer. Exclusions are honoured and recorded publicly (POLICY.md).
- **An install or runtime problem**: `python3 skills/unreleased/scripts/unreleased.py doctor --offline` output plus your
  Python version in the issue.
- **Questions and ideas**: GitHub Discussions on this repository.
